# Code of Conduct

RAP twin is a private project owned by Riaan Attar. Anyone given access to the repository, the deployed service or the project materials is expected to follow these rules.

## Expected behaviour
- Be respectful and professional with the owner and with other people involved.
- Use the project only for the purpose you were given access for.
- Keep the code, data, credentials and unpublished results confidential.
- Give accurate credit and report results honestly.

## Not acceptable
- Copying, forking, redistributing or reusing the code, documentation or figures without written permission (see [LICENSE](LICENSE)).
- Harassment, discrimination or abusive language of any kind.
- Probing, attacking or overloading the deployed service, or sharing API keys.
- Presenting this work, or any part of it, as your own.
